# Tugas 1 Pemrograman Web II

Buatlah sebuah database dengan nama universitas, dimana database tersebut memiliki sebuah tabel dengan nama mahasiswa. Tabel mahasiswa memiliki field sebagai berikut:

```
id (Integer / Primary Key / Auto Increment).
nama (Varchar 255 / Not Null).
nim (Varchar 255 / Not Null).
jenis_kelamin (Enum [laki-laki/perempuan] / Not Null)
kelas (Varchar 255 / Not Null)
program_studi (Varchar 255 / Not Null)
angkatan (Varchar 255 / Not Null)
```

Selanjutnya masukan data terlampir ke database. Hubungkan database dengan PHP dan tampilkan data yang telah di input pada halaman web dalam bentuk tabel.

Mekanisme pengumpulan Tugas 1:

Folder program yang berisi source code dan file export database (.sql) di compress dalam bentuk (.ZIP).
